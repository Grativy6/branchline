# Branchline

Branchline is a desktop app for keeping AI conversations in branches, working
with different models, and carrying useful context forward. It is being built
around local conversation storage, visible choices about sharing, and tools
that stay within the permissions the user gives them.

Founded and developed by **Christopher Daniel Pang**.

## Public release status

This repository is the public project home. It currently contains the project
introduction and licensing notices. **Application source and downloads have
not been published here yet.** A public release will be announced here when
its source, packages, instructions and release limits are ready together.
