# Branchline v0.8 Preview

This preview makes the existing Branchline workspace available as a portable
Windows x64 download. Extract the complete ZIP and open `Branchline.Preview.exe`.
Bring a local model connection or your own eligible ChatGPT account.

The cleanup gives the download a generic first launch, an official hash-pinned
Codex runtime, complete offline component notices, a native-library source
companion, and practical setup and recovery instructions. Dream's status now
describes what the app has recorded. The window, Home badge and About page
identify the v0.8 milestone.

The source export is Apache-2.0 for the covered application, attributed to
Christopher Daniel Pang. It contains the build inputs and tests without the
private development history, conversations, legal files or trained models.
Included components retain their own terms.

Existing preview users keep the same local data directory. Keep the previous
app and a backup while trying an update. See [START-HERE.md](START-HERE.md).

## Verification and remaining checks

The source suite passes 314 tests. Synthetic checks exercise the official
provider runtime's restricted tools, pictures, streaming and cancellation.
The built package passes first conversation, restart, backup/recovery, image
preservation, unavailable-model handling, and reopening with the prior preview.
Browser checks cover first setup, Tend, a conversation, notices and a narrow
window. These checks use synthetic data and no paid model requests.

The package is **unsigned**. Native-window launch on a separate Windows
machine, a missing-WebView2 installation, real account sign-in and inference,
and hardware-specific GPU behavior remain outside these results. A new data
folder on the development PC does not substitute for those checks.

Tend execution, in-app Dream training/scheduling, executable external agents,
simultaneous peer streams and the full Finis Solutus game interface remain
planned. See [PREVIEW-LIMITS.md](PREVIEW-LIMITS.md).

Use [BUG-REPORT.md](BUG-REPORT.md) for a small, reviewed report. Share a
synthetic example where possible; keep your account folder and private
conversation backups to yourself.
