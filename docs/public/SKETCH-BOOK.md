# Sketch Book

Open **Sketch Book** below New branch. Keep small project memories in **Ideas**,
shape them in **In-process**, and move ready plans to **Schematics**. A stage is
an organizational choice. Saving or selecting a schematic never starts work.

Choose **New sketch** to write or paste text, or **Save as sketch** below a model's
saved reply. A fresh manual sketch starts independently, even with a conversation
selected behind the book. Its source reads **Created in Sketch Book**. A sketch
saved from a reply or written by a model keeps its actual source and attribution.
Any permitted branch can use the shared book; a source link does not own an idea.
Edit its title, stage and text in the separate editor. Each save keeps the earlier
version. Existing source desk, branch and model reply remain linked;
renaming or moving a copy does not rewrite their recorded origin. Unfinished
editor text is kept locally as a draft. Save it to create a new saved version.

The book remembers its own window size. Drag the lower-right control or focus
it and use arrow keys. **Reset size** restores its default. Narrow windows keep
horizontal scrolling for the three columns. Activity and Stop remain available.

**Use in conversation** attaches a fixed saved copy to an existing conversation or a new
branch. It keeps the destination's unsent message. If another text file is
attached, choose a new branch or handle that attachment first. Choose the models
and send normally when ready. Editing the original sketch later does not change
copies already attached or sent. Open source returns to its originating branch,
including archived sources, without restoring them automatically.

**Archives** is at the bottom of the book. Restore returns a sketch to its saved
stage. Delete asks first and removes it from the book and model tools. It does
not erase the journal, saved backups, or copies already shared in conversations.
Use **Export .md** for the saved text. Unfinished changes must be saved first to
appear in that export. The workspace backup/export carries the full saved book.

## Letting a model use the book

1. In **Model access**, choose a saved connection and allow **Read sketches** or
   **Read, create and edit sketches**. Access starts off. It covers the book across
   this workspace's desks and branches, including explicitly requested archives.
2. In its **Coat pockets**, select **Read Sketch Book** and, for editing,
   **Create/edit sketches**. Leave **Tools** on for the conversation.
3. Ask the model to find, read, create or revise a sketch. A successful save shows
   **Open saved sketch** below its reply and records the model and saved version.

Reading does not open source conversations. Editing permits narrow saved-sketch
changes, including creating a new sketch; it does not permit deletion, archiving,
moving a copy, changing permissions or running a schematic. Tools cannot expand
their own permissions. A competing edit is held for review instead of overwriting
the newer version. Earlier saves remain if you Stop afterward. Stop before a save
is admitted prevents that write.

Grants belong to the local workspace and exact model connection. Imported Coats
and exported sketches contain no portable access grant. A different connection
needs review. A desk that has received book material may carry derived references
in shared memory, so a new recipient is checked before receiving that desk's
context. Revoking access stops new library calls; it cannot retract material
already delivered to that connection or remove it from conversation history.
Visiting providers receive the material their approved model reads. Background
handoff writers and hearth peers receive no library-writing tools in this preview.

Sketches hold up to **128 KiB of UTF-8 text**. Models read bounded pages and edit
small exact passages under the normal tool allowance. Long projects may take
several replies. Models can misunderstand instructions or fail to call a tool;
the visible saved record is the result to check.

## Comparing versions

Use a separate workspace for this preview. New sketch records and tool receipts
may not be understood by an older Branchline. Before upgrading your everyday
app, keep its verified backup. Roll back by pairing the older app with that
pre-upgrade workspace, preserving newer history separately.
