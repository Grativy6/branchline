# Branchline preview bug report

Report a reproducible problem at [Branchline Issues](https://github.com/Grativy6/branchline/issues).
For a vulnerability or exposed private information, use the private reporting
route described in [SECURITY.md](SECURITY.md), not a public issue.

Please review what you share. A short synthetic example is usually more useful
than a complete private conversation. Remove account names, tokens, personal
paths, private text and pictures from screenshots and logs.

- Branchline version (Settings → About & licences):
- Windows version and CPU architecture:
- Connection type (local model or ChatGPT); model identifier if relevant:
- What I was trying to do:
- Steps to repeat it with a small example:
- What I expected:
- What happened:
- Exact error text, with private details removed:
- Did stopping/reopening change it?:
- Optional screenshot or small synthetic export, inspected before attaching:

Do not attach your account folder, credentials, full workspace, or an unreviewed
backup. Nothing in this template submits or uploads a report automatically.
