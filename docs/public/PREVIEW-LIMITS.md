# Preview limits

Branchline v0.8.12-preview.3 is a preview for early testers. Back up important work.

- **Models:** the full installer includes stock Qwen3.5-4B; the app-only ZIP does not. No private Hearthline adapter, GPU service or paid allowance is included. Model answers can be wrong; a successful tool or picture check is not a general accuracy guarantee.
- **Computer tools:** an explicitly permitted foreground chair can read and
  change bounded text files. Programs, shell commands and screen control are
  unavailable. See [PC-ACCESS.md](PC-ACCESS.md) for exclusions, sharing and recovery.
- **Dream:** review, declared origins, notes and explicit earlier-entry organization
  are available. Verified selection covers stock bundled Qwen only; external Dream
  checkpoints cannot yet be reloaded and verified. See DREAM-REVIEW.md. Training, automatic learning,
  scheduling and retention controls are still under development. The app does
  not infer an external model's training history from its name.
- **Continuing hearth:** optional, sequential calls with separate recorded
  results under a shared allowance. Stop cancels active and queued work; restarting
  the app does not resume it. This is not simultaneous inference or a native
  model-state fork.
- **Agent profiles:** selected, versioned text with destination sharing review.
  Importing a repository's instructions does not run its code or connect its MCP tools.
- **Images:** still-image transport for compatible models, not a guarantee of
  visual comprehension. Imported image/text content cannot grant actions.
- **Retired experiences:** Tend and Finis Solutus creation and starters are archived.
  Existing desks, conversations and exact saved Coats remain supported.
- **Trust:** provenance, hashes and receipts are evidence. They are not truth,
  permission, ownership or protection against an attacker who controls the host.
  The bounded checks are not a claim of complete PAL, PECAN, PEA or PPP conformance.
- **Sketch Book:** 128 KiB saved text, manual/reply capture and explicitly enabled
  bounded chat tools. Saved memories and Schematics do not authorize execution.
  Deletion hides a sketch; existing journal history and shared copies remain.
  See [SKETCH-BOOK.md](SKETCH-BOOK.md) for permissions, sharing and recovery.
- **Platform:** Windows x64 only in this candidate. An unfamiliar Windows machine
  remains a separate release check from synthetic tests on the development PC.

Opening this preview starts no background trainer, application updater,
telemetry uploader, scheduled model job or public publishing action.

Microsoft prerequisites have separate update and diagnostic behavior under their own terms.

## Model archives

Archiving hides a saved model connection from active choices while preserving its personal entries, chair assignments, conversations and Dream history. It does not move or delete files on disk. Archive locations and copy checks are recorded maintenance information, not automatic verification of an attached drive. Use Copy folder location and Explorer to reach a separately prepared archive; native folder opening is not part of this preview. Returning an entry to the list does not load it or repair missing model files. Model files recorded as elsewhere remain blocked until you explicitly confirm their restoration.

Book of PEACHES on Toy Shelf opens a Coming later placeholder. It does not issue stamps, collect payment, connect an account or contact a service.
