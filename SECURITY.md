# Reporting a security problem

Please use GitHub's **Report a vulnerability** option on the
[Branchline security page](https://github.com/Grativy6/branchline/security/advisories/new).
This sends a private report to the repository's maintainers rather than a
public issue. A GitHub account is required by GitHub for that route.

Send the affected release, a short description and a small synthetic example
when possible. Do not send passwords, account tokens, private conversations,
private models or your complete workspace. Keep personal information out of
screenshots and logs. If the private route is unavailable, a public issue may
ask for a private contact method without including the vulnerability details.

This is an early preview with a small maintainer team. There is no guaranteed
response time, bug bounty or claim of comprehensive security certification.
The app does not upload a report or diagnostics automatically.
