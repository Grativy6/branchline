# Toy Shelf

Home’s Toy Shelf currently has **New desk**, followed by one quiet decorative
empty slot. Choose a name and confirm, or cancel. Opening it does not start a
model or run a plan. Tend and Finis Solutus are archived from the active app.
Existing conversations and saved Coats remain available.

**Manage Shelves** opens Settings → Toy Shelf. Show or hide New desk, then
**Save shelf**. **Restore default arrangement** prepares the starting arrangement
for saving. Hiding a tile leaves desks, conversations and permissions unchanged.
Sketch Book remains its own shared library.

Drag the bottom grip to change shelf height. Keyboard users can focus it and
use Up/Down (Shift for smaller steps); Home or **Reset height** restores the
default. The shelf follows Home’s width and remembers its preferred height
separately from Settings and Sketch Book. Small windows fit it temporarily
without forgetting that preference. No pixel counter is displayed.

Older three-tile settings still load with retired tiles omitted. The next
intentional shelf edit saves the current arrangement, keeping the prior height
and New desk visibility. The empty slot is decoration, not a button.
**Tools & connections** still opens image and local-tool setup. This preview
does not execute third-party apps, games or kernels from the shelf.
